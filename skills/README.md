# Public skills

OpenClaw loads every `<name>/SKILL.md` here as a managed skill (this folder is `~/.openclaw/skills` on the host).

Skills here are meant to be shared, so keep them free of names, accounts, IDs and other personal details. New skills start in `workspace/skills/` (private) and move here in a PR of their own once the owner decides to publish them. In a setup with a public upstream repo, this folder is shared: new skills are added to the upstream repo and sync down.
